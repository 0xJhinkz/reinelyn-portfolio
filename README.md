# Reinelyn Escandor — Portfolio

A responsive personal website based on Reinelyn Escandor's resume.

## Website

Static HTML/CSS/JavaScript, no build tools required. Includes About, Services, Experience, Education, Work Samples, and Contact sections.

## Deploy on Vercel

Import `0xJhinkz/reinelyn-portfolio` into Vercel. Select Other as framework preset, no build command, and `.` as output directory. Deploy.

Replace `assets/profile.svg` with a photo if authorized. The supplied monogram is a placeholder.
